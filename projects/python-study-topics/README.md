# Python Study Topics Menu

A small beginner exercise based on the concepts studied in *Python Crash Course, 3rd Edition*, Chapters 1–7.

This is a learning exercise—not a production application. The goal is to practice the fundamentals and understand every line before adding more features.

## Features

- Show a list of study topics
- Add a topic
- Remove the last topic
- Keep showing a menu until the user chooses to quit
- Handle empty topic names and an empty list

## Run the program

You need Python 3. Run this command from the project directory:

```bash
python3 study_topics.py
```

## Concepts used

- Variables and strings
- Lists
- `input()` and `strip()`
- `if`, `elif`, and `else`
- `while` and `for` loops
- `append()`, `pop()`, and `break`
- f-strings

There are no external dependencies, functions, exception handlers, or automated tests in this starter version.

## Practice ideas

1. Add an option to clear the topic list.
2. Prevent a topic from being added twice.
3. Let the user choose which topic to remove, rather than always removing the last one.

Try implementing these changes yourself first, using only the concepts you have studied so far.
